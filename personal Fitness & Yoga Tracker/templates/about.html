🔧 Technical Implementation

Arrays Used:

  • BEGINNER_ASANAS, INTERMEDIATE_ASANAS, ADVANCED_ASANAS - Arrays of yoga poses
  • PRANAYAMA, MEDITATION - Arrays for breathing & meditation techniques
  • day_themes - Array of daily focus themes
  • weekly_dist - Array tracking practice distribution
  • logs - Array of practice log entries

File I/O:

  • logs.json - Stores all practice logs
  • users.json - Stores user profiles
  • Functions: read_logs(), write_logs(), read_users(), write_users()

LLM Layer:

  • generate_weekly_plan() - Creates personalized 7-day yoga plan
  • analyze_progress() - Analyzes practice history using arrays
  • Rule-based AI mimicking LLM behavior for routine generation
